# 08 — Training Curriculum

## Learning approach

Each lesson follows: understand → observe → perform → verify → reflect. A learner should be able to explain the result, not merely copy commands.

## Module 1 — Developer workstation

**Outcome:** run the Flutter project locally.  
Practice: install Git/Flutter/Android SDK, run `flutter doctor`, resolve one environment issue.  
Evidence: terminal output and a successful app launch.

## Module 2 — Android device workflow

**Outcome:** deploy to the S25 Ultra.  
Practice: enable USB debugging, run `adb devices`, install a debug build.  
Evidence: app opens on the physical phone.

## Module 3 — Offline field journal

**Outcome:** capture and retrieve a field entry without connectivity.  
Practice: create three entries, enable airplane mode, restart the app, retrieve them.  
Evidence: entries persist offline.

## Module 4 — Documentary capture

**Outcome:** produce a complete, consent-aware media record.  
Practice: create a mock interview record with source ID, consent scope, language, attribution and asset links.  
Evidence: completed metadata checklist.

## Module 5 — Local model operations

**Outcome:** download, verify, load and test a supported model.  
Practice: install a small supported model first, run a smoke test, switch offline and repeat.  
Evidence: test log with model ID and runtime version.

## Module 6 — Responsible AI research

**Outcome:** distinguish evidence from generated interpretation.  
Practice: summarize a short transcript, list uncertain names and compare each claim with the source.  
Evidence: reviewed summary with corrections.

## Module 7 — Archive and retrieval

**Outcome:** organize records for later discovery.  
Practice: tag entries, link source media, search for a topic and inspect provenance.  
Evidence: a reproducible archive search.

## Module 8 — Hermes and automation

**Outcome:** run a safe, limited agent workflow.  
Practice: configure a read-only tool, generate a draft report, require confirmation before any external action.  
Evidence: tool permission checklist and execution log.

## Module 9 — Backup and recovery

**Outcome:** demonstrate a recoverable archive.  
Practice: create a backup, verify sample files, restore to a test location.  
Evidence: restore checklist.

## Module 10 — Release engineering

**Outcome:** produce a traceable APK build.  
Practice: run analysis/tests, trigger CI, download the APK artifact, install and smoke-test it.  
Evidence: build run ID, commit SHA and device test record.

## Completion checklist

- [ ] Can explain offline-first architecture.
- [ ] Can build and install a debug APK.
- [ ] Can create and retrieve a field entry offline.
- [ ] Can preserve original media and link derivatives.
- [ ] Can document consent and attribution.
- [ ] Can install and test a compatible local model.
- [ ] Can identify AI-generated content as a derivative.
- [ ] Can configure least-privilege agent tools.
- [ ] Can back up and verify an archive.
- [ ] Can produce a traceable release candidate.

Completion is a practical skills checklist, not an accredited qualification.
